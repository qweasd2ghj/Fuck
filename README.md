# 异想剧场 0.6.1 修正版

## 本次修复
- 移除向 SillyTavern 原生扩展菜单/顶部入口注入的代码。
- 只保留可拖动的独立悬浮入口，默认位于屏幕右下角。
- 在 JavaScript 中加入样式兜底注入，避免样式文件未被酒馆加载时，独立窗口以普通页面内容形式挤进顶部区域。
- ZIP 根目录直接放置 manifest.json、index.js、style.css，避免多套一层文件夹导致扩展加载路径异常。

## 安装
用本包替换原异想剧场扩展文件后刷新 SillyTavern。旧版数据存储键保持不变。

## 注意
此修正版针对截图中出现的顶部错位和入口侵入问题；仍需在实际设备上验证打开/关闭、拖动和不同屏幕尺寸。
