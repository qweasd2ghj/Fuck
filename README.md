# 异想剧场 0.6.2 修正版

## 本次修复
- 移除向 SillyTavern 原生扩展菜单/顶部入口注入的代码。
- 只保留可拖动的独立悬浮入口，默认位于屏幕右下角。
- 在 JavaScript 中加入样式兜底注入，避免样式文件未被酒馆加载时，独立窗口以普通页面内容形式挤进顶部区域。
- ZIP 根目录直接放置 manifest.json、index.js、style.css，避免多套一层文件夹导致扩展加载路径异常。

## 安装
用本包替换原异想剧场扩展文件后刷新 SillyTavern。旧版数据存储键保持不变。

## 注意
此修正版针对截图中出现的顶部错位和入口侵入问题；仍需在实际设备上验证打开/关闭、拖动和不同屏幕尺寸。


## 0.6.2 入口修复
- 恢复在聊天输入框魔棒（Extensions 下拉菜单）中的「异想剧场」菜单项。
- 保留右下角悬浮按钮作为备用入口。
- 不向酒馆顶部工具栏注入按钮。
- 初始化时等待 SillyTavern 上下文与界面就绪。


## 0.6.3 手机窗口布局修复
- 手机屏幕下剧场改为居中弹窗，不再铺满并覆盖酒馆顶部工具栏。
- 限制弹窗高度，给顶部工具栏和底部输入区留出空间。
- 保留魔棒入口与右下角悬浮入口。


## 0.6.4 手机端居中定位修复
- 修正运行时注入样式覆盖外部 CSS 的层叠顺序问题。
- 手机端居中规则直接追加到运行时样式末尾，并明确覆盖全屏定位属性。
- 限制弹窗高度并保留顶部、底部酒馆操作区域。


## 0.6.5 手机端居中结构修复
- 手机端不再依赖 top:50% / translateY 的定位组合。
- 弹窗改由全屏遮罩容器使用 Flexbox 真正水平、垂直居中。
- 遮罩挂载到 documentElement，避开酒馆页面容器可能存在的 transform 对 fixed 定位的影响。
- 限制弹窗最大宽度和高度，保留酒馆页面四周可见区域。
