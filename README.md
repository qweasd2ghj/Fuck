# 异想剧场 · Side Story

一个面向 SillyTavern 手机端的独立番外扩展。目标是在不改写主线聊天记录的前提下，提供独立的剧场窗口和番外历史。

## 当前版本

**v0.4.0 — Mobile Theater Library & Preset Modes**

### 功能
- 全屏覆盖式剧场窗口（Overlay）
- 两个入口：酒馆顶部工具栏、右下角悬浮按钮
- 每个剧场独立保存对话历史
- 可选择读取角色卡、User Persona 和最近主线聊天记录，并保存为背景快照
- 角色卡内嵌 Character Book 条目读取
- 自定义系统提示词、创作规则、破限/创作提示词模块
- 多预设管理、剧场 JSON 导入导出
- 使用酒馆当前 API 配置调用 `generateRaw()`

## 安装

在 SillyTavern 的「扩展」→「安装扩展」中，粘贴：

```text
https://github.com/qweasd2ghj/fuck
```

也可以将仓库克隆到当前用户的第三方扩展目录：

```bash
git clone https://github.com/qweasd2ghj/fuck.git side-story
```

然后重启 SillyTavern，并在扩展管理界面启用扩展。

> 仓库地址为 `https://github.com/qweasd2ghj/fuck`。默认分支建议使用 `main`。

## 隔离机制与限制

- 番外生成结果写入扩展自己的设置数据，不会追加到 `context.chat`。
- 生成时使用已保存的主线背景快照、本剧场历史和本轮输入，不自动携带实时主线聊天上下文。
- 创建剧场时会建立背景快照；需要同步新剧情时，可在设置中手动刷新。
- Quiet 模式可沿用酒馆当前聊天上下文和激活世界书；Raw 模式仍需通过角色卡快照和补充世界书栏提供设定。
- 本版沿用酒馆当前 API 预设，不对第三方中转强行覆盖未验证的高级参数。
- 群聊角色聚合、流式输出和更多生成参数适配仍待开发。

## 手机端说明

界面针对触屏与移动端安全区域做了适配。不同 SillyTavern 正式版、主题、扩展布局可能影响工具栏按钮的插入位置，需在实际环境验证。

## 安全提醒

不要将 API Key、访问令牌、私人聊天记录、角色卡隐私内容或其他凭据提交到公开仓库。公开仓库中的代码和文档任何人都可以查看和下载。

## 开发状态

这是开发预览版本，尚未在所有 Android + Termux + 第三方 API 中转组合上完成实机测试。Quiet 模式的提示词来源依赖酒馆当前所选 API 预设及其 Quiet 触发配置。提交 Issue 时请附上 SillyTavern 版本、浏览器、API 类型和控制台报错，并移除密钥及私人内容。
